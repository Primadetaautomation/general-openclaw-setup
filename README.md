# OpenClaw Setup Wizard

Universal setup wizard for deploying your own [OpenClaw](https://github.com/openclaw) AI assistant. Choose between **Cloudflare Workers** or **Docker/VPS** deployment, configure everything through a web interface, and deploy in minutes.

## Quick Start

```bash
git clone https://github.com/Primadetaautomation/general-openclaw-setup.git
cd general-openclaw-setup
npm install
npm run build
node dist/bin/create-moltbot.js
```

# English Guide

## What is this?

A local web-based setup wizard that helps you deploy OpenClaw (AI assistant) to either:

- **Cloudflare Workers** — Edge deployment with R2 storage, CF Access auth, and AI Gateway
- **Docker / VPS** — Self-hosted on any Linux server, Mac, or Windows with Docker

The wizard walks you through 9 configuration categories, validates your input, generates all necessary config files, and optionally deploys everything for you.

## Requirements

- **Node.js 20+**
- **For Cloudflare:** [Wrangler CLI](https://developers.cloudflare.com/workers/wrangler/) + Workers Paid plan
- **For Docker:** Docker + Docker Compose installed on your target server

## Installation

### Option 1: Clone and run locally

```bash
git clone https://github.com/Primadetaautomation/general-openclaw-setup.git
cd general-openclaw-setup
npm install
npm run build
node dist/bin/create-moltbot.js
```

### Option 2: Development mode

```bash
git clone https://github.com/Primadetaautomation/general-openclaw-setup.git
cd general-openclaw-setup
npm install
npm run dev
```

## How it works

### Step 1: Choose your platform

Select **Cloudflare Workers** or **Docker/VPS**. The wizard adapts its configuration options based on your choice.

### Step 2: Configure (9 categories)

| Step | Category | What you configure |
|------|----------|--------------------|
| 1 | **Core Settings** | Gateway token (auto-generated), dev mode |
| 2 | **AI Providers** | At least one: Anthropic, OpenAI, Gemini, Together AI, xAI |
| 3 | **Authentication** | Cloudflare Access (CF) or basic auth username/password (Docker) |
| 4 | **Chat Platforms** | Optional: Telegram, Discord, Slack bot tokens |
| 5 | **Storage** | R2 credentials (CF) or local Docker volumes (auto) |
| 6 | **Browser** | Optional: headless Chrome for web browsing capabilities |
| 7 | **Integrations** | Optional: RecruitFlow, LinkedIn, Late.dev |
| 8 | **Review** | Overview of all settings with masked secrets |
| 9 | **Deploy** | Generate files and/or deploy directly |

### Step 3: Deploy

**Cloudflare path:**
- Generates `secrets.sh` (wrangler secret put commands)
- Generates `.dev.vars` for local development
- Optionally runs the deployment for you

**Docker path:**
- Generates `docker-compose.yml` with OpenClaw + Caddy reverse proxy
- Generates `.env` with all your secrets
- Generates `Caddyfile` with automatic HTTPS and authentication
- Optionally includes headless Chrome container for browser capabilities

## Security

- The wizard runs **only on localhost** (127.0.0.1) — never exposed to the network
- Secrets stay in browser memory only, never stored on disk until you deploy
- No telemetry, no external API calls, no tracking
- Generated `.env` files are created with `chmod 600` (owner-only read/write)
- `.env` is automatically added to `.gitignore` in generated projects

# Nederlandstalige Handleiding

## Wat is dit?

Een lokale web-based setup wizard waarmee je je eigen OpenClaw AI-assistent kunt deployen naar:

- **Cloudflare Workers** — Edge deployment met R2 opslag, CF Access authenticatie en AI Gateway
- **Docker / VPS** — Self-hosted op elke Linux server, Mac of Windows met Docker

De wizard begeleidt je door 9 configuratiecategorieen, valideert je invoer, genereert alle benodigde configuratiebestanden en deployt optioneel alles voor je.

## Vereisten

- **Node.js 20+**
- **Voor Cloudflare:** [Wrangler CLI](https://developers.cloudflare.com/workers/wrangler/) + Workers Paid plan
- **Voor Docker:** Docker + Docker Compose geinstalleerd op je doelserver

## Installatie

### Optie 1: Kloon en draai lokaal

```bash
git clone https://github.com/Primadetaautomation/general-openclaw-setup.git
cd general-openclaw-setup
npm install
npm run build
node dist/bin/create-moltbot.js
```

Je browser opent automatisch op `http://localhost:3456` met de setup wizard.

### Optie 2: Development modus


## Hoe werkt het?

### Stap 1: Kies je platform

Selecteer **Cloudflare Workers** of **Docker/VPS**. De wizard past de configuratie-opties aan op basis van je keuze.

### Stap 2: Configureer (9 categorieen)

| Stap | Categorie | Wat je instelt |
|------|-----------|----------------|
| 1 | **Core** | Gateway token (automatisch gegenereerd), development modus |
| 2 | **AI Providers** | Minimaal een: Anthropic, OpenAI, Gemini, Together AI, xAI |
| 3 | **Authenticatie** | Cloudflare Access (CF) of gebruikersnaam/wachtwoord (Docker) |
| 4 | **Chat Platforms** | Optioneel: Telegram, Discord, Slack bot tokens |
| 5 | **Opslag** | R2 credentials (CF) of lokale Docker volumes (automatisch) |
| 6 | **Browser** | Optioneel: headless Chrome voor web browsing mogelijkheden |
| 7 | **Integraties** | Optioneel: RecruitFlow, LinkedIn, Late.dev |
| 8 | **Overzicht** | Review van alle instellingen met gemaskeerde secrets |
| 9 | **Deploy** | Bestanden genereren en/of direct deployen |

### Stap 3: Deploy

**Cloudflare pad:**
- Genereert `secrets.sh` (wrangler secret put commando's)
- Genereert `.dev.vars` voor lokale ontwikkeling
- Voert optioneel de deployment voor je uit

**Docker pad:**
- Genereert `docker-compose.yml` met OpenClaw + Caddy reverse proxy
- Genereert `.env` met al je secrets
- Genereert `Caddyfile` met automatische HTTPS en authenticatie
- Optioneel met headless Chrome container voor browser mogelijkheden

### Na het deployen

**Cloudflare:**
```bash
cd je-output-map
bash secrets.sh          # Zet alle secrets in Cloudflare Workers
cd moltbot-project
npm run deploy           # Build en deploy naar Cloudflare
```

**Docker:**
```bash
cd je-output-map
docker compose up -d     # Start alle containers
docker compose logs -f   # Bekijk de logs
```

Je OpenClaw instance is nu bereikbaar op je domein (Docker) of je Workers URL (Cloudflare).

## Veiligheid

- De wizard draait **alleen op localhost** (127.0.0.1) — nooit blootgesteld aan het netwerk
- Secrets blijven alleen in het browsergeheugen, worden pas opgeslagen bij deployment
- Geen telemetrie, geen externe API calls, geen tracking

- `.env` wordt automatisch toegevoegd aan `.gitignore` in gegenereerde projecten

## Veelgestelde Vragen

**V: Worden mijn API keys ergens opgeslagen?**
A: Nee. De wizard draait volledig lokaal. Je secrets worden alleen in je browser bewaard totdat je op "Deploy" klikt, waarna ze naar lokale bestanden geschreven worden.

**V: Kan ik de wizard draaien op mijn server?**
A: De wizard is bedoeld om lokaal te draaien op je eigen computer. De gegenereerde bestanden kopieer je vervolgens naar je server.

**V: Wat als ik later een instelling wil wijzigen?**
A: Draai de wizard opnieuw, of bewerk handmatig het `.env` bestand (Docker) of gebruik `wrangler secret put` (Cloudflare).

**V: Welke AI provider moet ik kiezen?**
A: Anthropic (Claude) is aanbevolen. Je kunt meerdere providers configureren — OpenClaw kiest automatisch het beste model.

**V: Moet ik Docker kennen?**
A: Minimaal. De wizard genereert alle bestanden. Je hoeft alleen `docker compose up -d` uit te voeren.
